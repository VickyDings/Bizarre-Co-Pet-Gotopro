                        How “all at the same time” actually works.
                        Networks marked intent have an official share URL, so
                        Publish opens them all together in one click. Networks marked
                        compose (Instagram, TikTok, YouTube, LinkedIn's
                        composer) have no public pre-fill API — no tool can post to them from a static page.
                        For those the caption is copied and the composer is opened, one tap each.
                        For genuinely hands-off simultaneous posting, set a
                        fan-out webhook in Settings (Zapier, Make, Buffer or your own endpoint):
                        one POST and every connected profile publishes at once.

     Honest limits
    
                    
      
                        
    • Browsers cannot post to Instagram, TikTok or YouTube from a page like this.
                            Those platforms have no public pre-fill URL. Anything claiming otherwise is either using
                            your logged-in session illegally or needs their official API with OAuth and app review.
                            The webhook route in Settings is the legitimate hands-off path.
      • 
                        
    • Popup blockers cap how many tabs open at once. The share window opens
                            every intent network in one click and then lists any the browser blocked with its own
                            button, so nothing is silently dropped.
      • 
                        
    • Competition labels are heuristics based on phrase length and specificity.
                            They are a shortlist to check in a real keyword tool, not search volume.
      • 
                        
    • Everything is stored in this browser (localStorage). Export the library
                            or commit the downloaded files to keep your work.
      • 
                        
    • The passcode is not security. Put HTTP auth, a host access rule or a real
                            login in front of admin.html before this site goes live.
      •
